★ Final Year Project · 2022 – 2026

SKY — Bilingual Desktop AI Agent

A voice agent that wakes on “Hey Sky”, understands any language — English, Urdu and more — and operates Windows through 14 tool modules — WhatsApp calls, Gmail, Spotify, YouTube, files, system settings, apps and games.

  • Silero VAD → Whisper large-v3-turbo (int8) → fuzzy command resolver → Gemini 2.5 Flash, with automatic fallback to local Llama 3.2 3B when offline.
  • Fit 11 models into an 8 GB VRAM budget on one RTX 5070; swapped Qwen 2.5 7B (11–20 s/reply) for Llama 3.2 3B (2–3 s) after benchmarking.
  • On-screen vision (YOLOv8n, EasyOCR), JSON-repair parser with Pydantic v2 validation, remote commands by email.
  • FastAPI + JWT + WebSocket backend with a live React 19 interface. ~15,400 lines of Python & TypeScript.
